# Семинар 4. Модель как исполнитель разметки

Практический ноутбук и материалы для занятия DLCOURSE-65.

Датасет — подвыборка [RuSentiment](https://github.com/strawberrypie/rusentiment). Лицензия данных: [CC BY-NC-SA 4.0](https://creativecommons.org/licenses/by-nc-sa/4.0/) — см. `data/SOURCE.md`.

Готовое разбиение содержит все 260 постов: `prompt_examples` — 60 (по 12 каждого класса), `calibration` — 50, `test` — 150. Банк few-shot уже включён в `artifacts/dataset_prepared.parquet` и `artifacts/split_manifest.json`; дополнительно собирать его в ноутбуке не нужно. Оценочные сплиты и их `task_id` сохранены без изменений.

## Содержимое

| Файл / папка | Что внутри |
|---|---|
| `seminar.ipynb` | ноутбук занятия |
| `.env.example` | шаблон секретов (скопировать в `.env`) |
| `data/` | `dataset.csv`, инструкция для людей, иллюстрации и схемы |
| `artifacts/` | сплиты, ответы людей, предсказания моделей, журнал вызовов |

## Как запустить

**Локально или в Colab с полным клоном:**

```bash
git clone https://github.com/MilordEv/seminar4-model-as-annotator-data.git
cd seminar4-model-as-annotator-data
```

Откройте `seminar.ipynb` — `data/` и `artifacts/` уже рядом.

**Только ноутбук в Colab:** при первом запуске ноутбук сам скачает `data/` и `artifacts/` из этого репозитория.

## Уверенность и порог: пересчёт 23 октября 2026

В `artifacts/model_predictions.parquet` обновлено поле `confidence` у всех 200 предсказаний (50 calibration + 150 test). Метки, сырые ответы классификатора, разбиение и человеческие ответы не изменены.

Метод `full_prompt_no_thinking_float32_v1`: отдельный проход с исходным постом и полной инструкцией, без уже сгенерированного рассуждения; `log_softmax` и нормировка пяти классов считаются в float32. Score относится к ранее выданной метке, а не обязательно к максимуму нового распределения. Он не является откалиброванной вероятностью правильного ответа.

- `confidence_threshold.json` — порог **0.9999918937683105**, выбранный только на calibration: максимум Macro-F1 принятых ответов при покрытии не ниже 25%. Проверен 41 уникальный порог; принято 15/50 постов calibration. На test правило фиксировано: принято 53/150 (35.3%).
- `threshold_curve.csv` — все проверенные пороги, покрытие и качество автоматически принятых ответов.
- `confidence_reliability.csv` и `confidence_run_summary.json` — диагностика и параметры воспроизводимости текущего пересчёта. `live_run_summary.json` относится к прежнему прогону и не описывает этот пересчёт.
- `hf_cache/confidence_8274c776baee88baa4b99e650ccd911d6d4c8d02966194c85cbe982921d73db1.json` — новый кэш score. Кэш старого метода сохранён отдельно; не подставляйте его под новый расчёт. В JSON сохранена полная точность чисел; при чтении через pandas используйте `precise_float=True`.
- `hybrid_routing.parquet` — решения нового фиксированного порога и итоговые метки гибридных схем на test. В `leaderboard.csv` пересчитаны четыре зависимые схемы; остальные строки не менялись.

На calibration AUROC нового score = 0.708, ECE = 0.338. Для гибрида «уверенная модель, иначе три человека» Macro-F1 на test = 0.778, среднее число человеческих назначений = 1.94 вместо 3. Схема «до пяти людей» по-прежнему использует качество трёх голосов как прокси: дополнительных ответов в данных нет.
